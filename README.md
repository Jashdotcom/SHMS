# Smart Hostel Management System (SHMS)

A Django-based web application for managing hostel/PG operations.

## Features
- Room booking
- Payment tracking
- Complaint system
- Admin dashboard

## Tech Stack
- Python (Django)
- SQLite
- Bootstrap

## Setup
1. Clone repo
2. Install dependencies with `pip install -r requirements.txt`
3. Run `python manage.py runserver`
